# Umami House — Korean Restaurant Ordering UI

> A full Korean restaurant ordering experience with 18 
> authentic dishes, category filters, item modals with 
> spicy level indicators, a slide-in cart, free delivery 
> threshold, and an order confirmation flow.

🔗 **Live demo:** [[Live link](https://restaurant-app-sand-nine.vercel.app/)]

---

## Overview

Umami House is a complete restaurant ordering UI built 
to simulate the experience of ordering from a real 
Korean restaurant online. The focus was on a rich 
product browsing experience — including spicy level 
indicators, item detail modals, and a smart cart that 
tracks progress toward free delivery.

---

## Features

- **18 authentic Korean dishes** — full menu with 
  descriptions, prices, and images
- **Category filters** — filter by dish type 
  (starters, mains, sides, drinks, etc.)
- **Item modals** — click any dish for a detailed 
  view with ingredients and spice level
- **Spicy level indicators** — visual indicator 
  showing mild / medium / hot / extra hot
- **Slide-in cart** — smooth cart drawer showing 
  all selected items
- **Free delivery threshold** — progress bar shows 
  how close you are to free delivery
- **Order confirmation flow** — complete checkout 
  with order summary and confirmation screen
- **Fully responsive**

---

## Key Implementation Details

- Cart total logic with real-time free delivery 
  threshold calculation
- Item modal state managed with useState — 
  opens correct dish data dynamically
- Spicy level system — dishes tagged with a 
  heat level value mapped to visual indicators
- Category filter using Array.filter on the 
  full menu data array
- TypeScript interfaces for menu items, 
  cart state, and order data
